# Allhouse 0.2.0 · Local alpha

**ดาวน์โหลด `Allhouse-Setup-0.2.0.exe` แล้วดับเบิลคลิก ติดตั้งจบในไม่กี่วินาที ไม่ต้องใช้สิทธิ์แอดมิน**

## มีอะไรใหม่
- **ป้ายโซเชียลมีเดีย (Social Media Rotator)**: วิดเจ็ต OBS ใหม่ บอกช่องทางโซเชียลของคุณ สลับไอคอน + ชื่อบัญชีทีละช่องทาง (สูงสุด 12 ช่อง, 13 แพลตฟอร์ม)
- **เสียง AI ไทยแบบออฟไลน์**: 3 เสียง ทำงานในเครื่อง ดาวน์โหลดเมื่อกดเองเท่านั้น (ใช้ได้เฉพาะงานที่ไม่ใช่เชิงพาณิชย์)
- แท็บวิดเจ็ต OBS จัดกลุ่มตามแพลตฟอร์มที่รองรับ (ทุกแพลตฟอร์ม / บางแพลตฟอร์ม / เฉพาะ TikTok)
- หน้าแชทและกิจกรรมแบ่งหน้าได้ 10 / 20 / 50 รายการต่อหน้า
- **แจ้งเวอร์ชันใหม่ตอนเปิดแอพ**: ถ้ามีรุ่นใหม่บน GitHub จะขึ้นกล่องชวนไปดาวน์โหลด (เริ่มทำงานตั้งแต่รุ่นนี้เป็นต้นไป)
- แก้: ปุ่มเปิดวิดเจ็ตของขวัญในเบราว์เซอร์ใช้ไม่ได้

## What’s new (English)
- **Social Media Rotator**: a new OBS widget that cycles your social icons and handles (up to 12 channels, 13 networks)
- **Offline Thai AI voices**: three voices that run on your computer; downloaded only when you press Download (non-commercial use only)
- OBS widget tabs are grouped by platform support
- Chat & activity list pages: 10 / 20 / 50 per page
- **Update check at start-up**: a dialog offers the download when a newer release is on GitHub (works from this version on)
- Fix: opening the gift widget in a browser was refused

## ติดตั้ง
1. ดาวน์โหลด `Allhouse-Setup-0.2.0.exe` (~131 MB)
2. ถ้า Windows ขึ้น "Windows protected your PC" ให้กด **More info → Run anyway** (ตัวติดตั้งยังไม่ได้เซ็นดิจิทัล)
3. กด **ติดตั้ง** — Allhouse จะอยู่ในเมนู Start (และบนเดสก์ท็อปถ้าเลือกไว้)

ถอนการติดตั้งได้จาก Settings → Apps หรือ "Uninstall Allhouse" ในโฟลเดอร์โปรแกรม ห้องและการตั้งค่าของคุณจะยังอยู่ เว้นแต่เลือกให้ลบ

## Install (English)
Download `Allhouse-Setup-0.2.0.exe` and double-click it. It installs for your Windows user only (no admin), adds a Start menu entry, and updates an existing install in place. The installer isn't code-signed yet, so SmartScreen may ask you to choose **More info → Run anyway**.

Requires Windows 10 or 11 (64-bit).

SHA-256 (`Allhouse-Setup-0.2.0.exe`): see `Allhouse-Setup-0.2.0.exe.sha256` next to the download.
