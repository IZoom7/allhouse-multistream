# Allhouse 0.1.0 · Local alpha

**ดาวน์โหลด `Allhouse-Setup-0.1.0.exe` แล้วดับเบิลคลิก ติดตั้งจบในไม่กี่วินาที ไม่ต้องใช้สิทธิ์แอดมิน**

- รวมแชท Twitch, YouTube, Kick และ TikTok (ผ่าน TikFinity) ไว้ในห้องเดียว
- วิดเจ็ต OBS: แชท ผู้ติดตาม สมาชิก ของขวัญ แบนเนอร์ พร้อม Custom CSS
- บอทอ่านแชทภาษาไทย/อังกฤษ (เสียง Windows หรือเสียงออนไลน์)
- ทุกอย่างอยู่ในเครื่องคุณ ไม่ต้องสมัครบัญชี

## ติดตั้ง
1. ดาวน์โหลด `Allhouse-Setup-0.1.0.exe` (~131 MB)
2. ถ้า Windows ขึ้น "Windows protected your PC" ให้กด **More info → Run anyway** (ตัวติดตั้งยังไม่ได้เซ็นดิจิทัล)
3. กด **ติดตั้ง** — Allhouse จะอยู่ในเมนู Start (และบนเดสก์ท็อปถ้าเลือกไว้)

ถอนการติดตั้งได้จาก Settings → Apps หรือ "Uninstall Allhouse" ในโฟลเดอร์โปรแกรม ห้องและการตั้งค่าของคุณจะยังอยู่ เว้นแต่เลือกให้ลบ

## Install (English)
Download `Allhouse-Setup-0.1.0.exe` and double-click it. It installs for your Windows user only (no admin), adds a Start menu entry, and updates an existing install in place. The installer isn't code-signed yet, so SmartScreen may ask you to choose **More info → Run anyway**.

Requires Windows 10 or 11 (64-bit).

SHA-256 (`Allhouse-Setup-0.1.0.exe`): see `Allhouse-Setup-0.1.0.exe.sha256` next to the download.
