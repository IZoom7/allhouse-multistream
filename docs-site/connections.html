02 · CONNECTIONS

เชื่อมต่อแพลตฟอร์มConnections

ใส่ชื่อช่องแล้วกดเชื่อมต่อ แชทและการแจ้งเตือนจริงจะเข้ามาที่ห้องแชทและ OBS แอพจำไว้และต่อให้เองทุกครั้งที่เปิด

Enter your channel and press Connect. Real chat and alerts flow into the chat room and OBS, and the app reconnects by itself every time it starts.

02

Twitch

ใส่ชื่อช่อง (ที่อยู่หลัง twitch.tv/) แล้วกดเชื่อมต่อ ไม่ต้องล็อกอิน อ่านแชทและการซับ/ซับต่อ/ของขวัญซับได้ทันที การแจ้งเตือนผู้ติดตามใหม่ของ Twitch ต้องล็อกอิน จะเปิดให้ใช้ในรุ่นถัดไป

Enter the channel name (the part after twitch.tv/) and press Connect. No sign-in needed: chat, subs, resubs and gifted subs arrive straight away. New-follower alerts on Twitch need a sign-in and will come in a later release.

03

YouTube

ใส่ @ชื่อช่อง ถ้ายังไม่ได้เริ่มไลฟ์ แอพจะรอแล้วต่อให้เองเมื่อช่องเริ่มไลฟ์ หรือใส่ลิงก์ไลฟ์ตรงๆ ก็ได้ แชทอาจช้ากว่าจริงประมาณ 5 วินาที

Enter your @channel. If you aren’t live yet, the app waits and joins as soon as you start, or paste a live link directly. Chat can lag about 5 seconds.

YouTube ไม่มีช่องทางอ่านแชทสำหรับแอพในเครื่องแบบง่าย Allhouse ใช้ช่องทางเดียวกับหน้าต่างแชทของ YouTube (ไม่ใช่ API ทางการ) อาจหยุดทำงานได้ถ้า YouTube เปลี่ยนระบบ

YouTube has no simple chat API for desktop apps. Allhouse uses the same feed as YouTube’s chat pop-out (not the official API), so it may stop working if YouTube changes it.

04

Kick

ใส่ชื่อช่องจาก kick.com/ชื่อ ได้ทั้งแชท ซับ ของขวัญซับ และผู้ติดตามใหม่

Enter the name from kick.com/name to get chat, subs, gifted subs and new followers.

Kick ไม่มี API แชทสาธารณะ Allhouse ใช้ช่องทางเดียวกับเว็บ kick.com อาจหยุดทำงานได้ถ้า Kick เปลี่ยนระบบ

Kick has no public chat API. Allhouse uses the same feed as kick.com, so it may stop working if Kick changes it.

แก้ไขข้อมูลไลฟ์ Kick (ชื่อไลฟ์ หมวด แท็ก)Edit your Kick stream info (title, category, tags)

  1. สร้างแอพนักพัฒนาที่ kick.com → Settings → Developer ใส่ Redirect URL http://localhost:19325/kick/callback และติ๊กแค่ Read user information, Read channel information, Update channel information (ห้ามติ๊ก Read stream key)
  2. ใน Allhouse กด “แก้ไขข้อมูลไลฟ์” บนการ์ด Kick แล้ววาง Client ID และ Client Secret (Secret ถูกเข้ารหัสด้วย Windows เก็บในเครื่องนี้เท่านั้น)
  3. กด “ล็อกอินด้วย Kick” แล้วอนุญาตในเบราว์เซอร์
  4. แก้ชื่อไลฟ์ ค้นหาหมวด และแท็ก (สูงสุด 10) แล้วกดบันทึก ภาษาและ 18+ แก้ผ่าน API ไม่ได้ ต้องแก้บนเว็บ Kick
  1. Create a developer app at kick.com → Settings → Developer. Set the Redirect URL to http://localhost:19325/kick/callback and tick only Read user information, Read channel information and Update channel information (never Read stream key).
  2. In Allhouse, press “Edit stream info” on the Kick card and paste the Client ID and Client Secret (the secret is encrypted by Windows and stays on this computer).
  3. Press “Sign in with Kick” and allow access in your browser.
  4. Edit the title, search for a category, add up to 10 tags, then save. Language and 18+ can’t be changed through the API; change those on kick.com.
05

TikTok (ผ่าน TikFinity)TikTok (through TikFinity)

  1. ติดตั้ง TikFinityInstall TikFinityดาวน์โหลด TikFinity Desktop (ฟรี) จาก tikfinity.zerody.oneDownload TikFinity Desktop (free) from tikfinity.zerody.one
  2. ล็อกอิน TikTokSign in to TikTokใน TikFinity ใส่ชื่อบัญชี TikTok ของคุณEnter your TikTok account in TikFinity
  3. เปิดค้างไว้Leave it openTikFinity ต้องเปิดอยู่ตลอดเวลาที่ไลฟ์TikFinity must stay open while you are live
  4. กดเชื่อมต่อPress Connectใน Allhouse การ์ด TikTok → เชื่อมต่อIn Allhouse: TikTok card → Connect

TikFinity ส่งข้อมูลมาให้เฉพาะตอนที่บัญชีไลฟ์อยู่ ถ้ายังไม่ได้ไลฟ์ สถานะจะ “เชื่อมแล้ว” แต่ยังไม่มีแชทเข้ามา เป็นเรื่องปกติ

TikFinity only sends events while the account is live. Before you go live the card says “Connected” but no chat arrives; that’s normal.
