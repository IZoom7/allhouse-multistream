02 · CONNECTIONS

เชื่อมต่อแพลตฟอร์ม

ใส่ชื่อช่องแล้วกดเชื่อมต่อ แชทและการแจ้งเตือนจริงจะเข้ามาที่ห้องแชทและ OBS แอพจำไว้และต่อให้เองทุกครั้งที่เปิด

01

แต่ละแพลตฟอร์มได้อะไร

แพลตฟอร์มใส่อะไรแชทสมาชิก/ซับผู้ติดตามของขวัญ
Twitchชื่อช่อง เช่น twitch.tv/ชื่อ✓✓เร็วๆ นี้ (ต้องล็อกอิน)—
YouTube@ชื่อช่อง หรือลิงก์ไลฟ์✓ + Super Chat✓ สมาชิกYouTube ไม่ส่งให้—
Kickชื่อช่อง kick.com/ชื่อ✓✓✓—
TikTokเปิด TikFinity ไว้ แล้วกดเชื่อมต่อ✓✓✓✓
02

Twitch

ใส่ชื่อช่อง (ที่อยู่หลัง twitch.tv/) แล้วกดเชื่อมต่อ ไม่ต้องล็อกอิน อ่านแชทและการซับ/ซับต่อ/ของขวัญซับได้ทันที การแจ้งเตือนผู้ติดตามใหม่ของ Twitch ต้องล็อกอิน จะเปิดให้ใช้ในรุ่นถัดไป

03

YouTube

ใส่ @ชื่อช่อง ถ้ายังไม่ได้เริ่มไลฟ์ แอพจะรอแล้วต่อให้เองเมื่อช่องเริ่มไลฟ์ หรือใส่ลิงก์ไลฟ์ตรงๆ ก็ได้ แชทอาจช้ากว่าจริงประมาณ 5 วินาที

YouTube ไม่มีช่องทางอ่านแชทสำหรับแอพในเครื่องแบบง่าย Allhouse ใช้ช่องทางเดียวกับหน้าต่างแชทของ YouTube (ไม่ใช่ API ทางการ) อาจหยุดทำงานได้ถ้า YouTube เปลี่ยนระบบ

04

Kick

ใส่ชื่อช่องจาก kick.com/ชื่อ ได้ทั้งแชท ซับ ของขวัญซับ และผู้ติดตามใหม่

Kick ไม่มี API แชทสาธารณะ Allhouse ใช้ช่องทางเดียวกับเว็บ kick.com อาจหยุดทำงานได้ถ้า Kick เปลี่ยนระบบ

แก้ไขข้อมูลไลฟ์ Kick (ชื่อไลฟ์ หมวด แท็ก)

  1. สร้างแอพนักพัฒนาที่ kick.com → Settings → Developer ใส่ Redirect URL http://localhost:19325/kick/callback และติ๊กแค่ Read user information, Read channel information, Update channel information (ห้ามติ๊ก Read stream key)
  2. ใน Allhouse กด “แก้ไขข้อมูลไลฟ์” บนการ์ด Kick แล้ววาง Client ID และ Client Secret (Secret ถูกเข้ารหัสด้วย Windows เก็บในเครื่องนี้เท่านั้น)
  3. กด “ล็อกอินด้วย Kick” แล้วอนุญาตในเบราว์เซอร์
  4. แก้ชื่อไลฟ์ ค้นหาหมวด และแท็ก (สูงสุด 10) แล้วกดบันทึก ภาษาและ 18+ แก้ผ่าน API ไม่ได้ ต้องแก้บนเว็บ Kick
05

TikTok (ผ่าน TikFinity)

  1. ติดตั้ง TikFinityดาวน์โหลด TikFinity Desktop (ฟรี) จาก tikfinity.zerody.one
  2. ล็อกอิน TikTokใน TikFinity ใส่ชื่อบัญชี TikTok ของคุณ
  3. เปิดค้างไว้TikFinity ต้องเปิดอยู่ตลอดเวลาที่ไลฟ์
  4. กดเชื่อมต่อใน Allhouse การ์ด TikTok → เชื่อมต่อ

TikFinity ส่งข้อมูลมาให้เฉพาะตอนที่บัญชีไลฟ์อยู่ ถ้ายังไม่ได้ไลฟ์ สถานะจะ “เชื่อมแล้ว” แต่ยังไม่มีแชทเข้ามา เป็นเรื่องปกติ

06

สถานะบนการ์ด

ปิดอยู่ยังไม่ได้เชื่อม หรือกดตัดการเชื่อมต่อแล้ว
กำลังเชื่อม…กำลังติดต่อแพลตฟอร์ม
เชื่อมแล้วรับข้อมูลได้ จอเขียวบอกช่องที่ต่ออยู่และจำนวนรายการที่รับมา
กำลังลองใหม่หลุดหรือยังไม่ได้ไลฟ์ แอพจะลองใหม่เองทุก 2–60 วินาที
เชื่อมไม่ได้ชื่อช่องผิดหรือไม่มีช่องนี้ แก้ชื่อแล้วกดเชื่อมต่อใหม่
