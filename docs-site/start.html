01 · GETTING STARTED

เริ่มต้นใช้งาน

เปิดแอพ รู้จักแต่ละเมนู และเรื่องพื้นฐานที่ช่วยให้ไม่งงตอนไลฟ์จริง

01

เปิดแอพ

ดับเบิลคลิก Start Allhouse.cmd ในโฟลเดอร์ของโปรแกรม ครั้งแรกแอพจะเตรียมไฟล์ก่อน อาจใช้เวลาสักครู่ ครั้งต่อไปจะเปิดเร็วขึ้น

เปิด Allhouse ได้ทีละหน้าต่าง ถ้าเปิดซ้ำ แอพจะพาไปหน้าต่างเดิม และต้องเปิดแอพค้างไว้ตลอดที่ไลฟ์ วิดเจ็ตใน OBS ถึงจะทำงาน

02

รู้จักหน้าจอ

ห้องสตรีมภาพรวม: เชื่อมไว้กี่แพลตฟอร์ม วิดเจ็ตเปิดกี่ตัว บอทอ่านแชทเปิดอยู่ไหม และแชทล่าสุด
เชื่อมต่อแพลตฟอร์มใส่ชื่อช่อง Twitch / YouTube / Kick และเชื่อม TikTok ผ่าน TikFinity
วิดเจ็ต OBSลิงก์และการตั้งค่าของวิดเจ็ตแต่ละตัว (แชท ผู้ติดตาม สมาชิก ของขวัญ แบนเนอร์)
แชทและกิจกรรมแชทจากทุกแพลตฟอร์มรวมกัน ส่งกิจกรรมทดสอบ คิวการแจ้งเตือน หน้าต่างแชทแยก
บอทอ่านแชทเลือกเสียง ความเร็ว ความดัง และกฎว่าจะอ่านแชทจากที่ไหน
ตั้งค่าชื่อห้อง ภาษา ธีม สำรองและนำเข้าข้อมูล ล้างประวัติ
03

บันทึกอัตโนมัติ และ “เผยแพร่”

ทุกการตั้งค่าบันทึกลงเครื่องให้เองทันที ไม่มีปุ่มเซฟ (ดูจุด “บันทึกในเครื่องแล้ว” ที่มุมขวาบน) ยกเว้นวิดเจ็ต OBS ที่แก้แล้วจะยังเป็นฉบับร่าง ต้องกด เผยแพร่ทุกวิดเจ็ต ก่อน OBS ถึงจะเปลี่ยน กันไม่ให้ผู้ชมเห็นตอนกำลังแต่ง

04

ข้อมูลทดสอบ กับ ของจริง

ทุกอย่างที่คุณกดส่งเองจะติดป้าย ทดสอบ ในแอพ และ TEST บนหน้า OBS แชทและการแจ้งเตือนจริงจากแพลตฟอร์มจะไม่มีป้ายนี้

ถ้ากำลังไลฟ์อยู่แล้วกดส่งทดสอบไป OBS ผู้ชมจะเห็นด้วย (มีป้าย TEST) ทดสอบก่อนเริ่มไลฟ์จะดีที่สุด

05

ภาษาและธีม

  • ปุ่ม TH / EN มุมขวาบน สลับภาษาไทย/อังกฤษ
  • ปุ่มพระจันทร์/ดวงอาทิตย์มุมซ้ายล่าง สลับโหมดสว่าง (ครีม) และมืด (ถ่าน) หรือตั้ง “ตามเครื่อง” ในหน้าตั้งค่า
