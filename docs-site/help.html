แก้ปัญหาและข้อมูลHelp & info

อาการที่เจอบ่อยและวิธีแก้ การสำรองข้อมูล และข้อมูลของคุณไปที่ไหนบ้าง

Common problems and fixes, backups, and where your data goes.

01

อาการที่เจอบ่อยCommon problems

OBS ไม่เห็นอะไรNothing in OBSเช็กว่าแอพเปิดอยู่ ลิงก์ถูกวาง และกด “เผยแพร่ทุกวิดเจ็ต” แล้ว ลองกดปุ่มทดสอบของวิดเจ็ตนั้นCheck the app is open, the link is pasted, and you pressed “Publish all widgets”. Then press that widget’s test button.
ทดสอบแล้วไม่ขึ้นTest doesn’t showดูข้อความแจ้งในแอพ: วิดเจ็ตอาจปิดอยู่ คิวพักอยู่ หรือยังไม่มีหน้าวิดเจ็ตเปิดใน OBSRead the app’s message: the widget may be off, the queue paused, or no widget page open in OBS.
เสียงแจ้งเตือนไม่ออกในไลฟ์No alert sound on streamติ๊ก “Control audio via OBS” ใน Browser Source แล้วดูแถบเสียงใน OBS Audio MixerTick “Control audio via OBS” in the Browser Source and watch the OBS Audio Mixer.
ไม่มีเสียงไทยNo Thai voiceเพิ่มเสียงไทยใน Windows (Settings → Time & language → Speech) หรือใช้เสียงออนไลน์ในหน้าบอกอ่านแชทAdd a Thai voice in Windows (Settings → Time & language → Speech) or use online voices on Chat TTS.
YouTube “กำลังลองใหม่”YouTube “Retrying”ช่องยังไม่ได้ไลฟ์ แอพจะต่อให้เองเมื่อเริ่มไลฟ์The channel isn’t live yet; the app joins by itself when you start.
TikTok “TikFinity is not running”เปิด TikFinity Desktop และล็อกอิน TikTok ไว้ก่อน แล้วกดเชื่อมต่อใหม่Open TikFinity Desktop, sign in to TikTok, then connect again.
เปิดแอพไม่ขึ้น: Port 19324Won’t start: Port 19324มี Allhouse อีกตัวเปิดอยู่ ปิดตัวนั้นก่อนแล้วเปิดใหม่Another Allhouse is running. Close it and open the app again.
แชทจริงไม่ถูกอ่านReal chat not read aloudเช็กว่าบอทเปิดอยู่ แพลตฟอร์มนั้นไม่ได้ปิดเสียง และชื่อไม่ได้อยู่ในรายชื่อที่ไม่อ่านCheck Chat TTS is on, that platform isn’t muted, and the name isn’t on the never-read list.
Windows เตือนตอนติดตั้งWindows warns on installตัวติดตั้งยังไม่ได้เซ็นดิจิทัล กด More info → Run anywayThe installer isn’t code-signed yet. Choose More info → Run anyway.
02

สำรองและนำเข้าBackup and import

  • ส่งออกไฟล์สำรอง: เก็บการตั้งค่า วิดเจ็ต รูป และเสียงไว้ในไฟล์เดียว ไม่รวมประวัติแชทและลิงก์ OBS ส่วนตัว
  • นำเข้า: ข้อมูลจากไฟล์จะเข้ามาเป็น ฉบับร่าง OBS ยังแสดงแบบเดิมจนกว่าจะกดเผยแพร่ บอทอ่านแชทจะถูกปิดไว้ก่อนเพื่อความปลอดภัย
  • ล้างประวัติ: ลบแชทและกิจกรรมที่เก็บไว้ (เก็บล่าสุดสูงสุด 200 รายการ) และล้างคิวการแจ้งเตือน
  • Export backup: your settings, widgets, images and sounds in one file. Chat history and your private OBS links are left out.
  • Import backup: the file comes in as a draft; OBS keeps the current layout until you publish. Chat TTS is switched off to be safe.
  • Clear history: removes stored chat and events (the latest 200 are kept) and empties the alert queue.
03

ข้อมูลของคุณไปที่ไหนWhere your data goes

ในเครื่องOn your PCการตั้งค่า ประวัติ รูป เสียง และลิงก์ OBS เก็บในเครื่องนี้เท่านั้นSettings, history, images, sounds and OBS links stay on this computer.
เสียงออนไลน์Online voicesถ้าเลือกเสียงออนไลน์ ข้อความที่จะอ่านจะถูกส่งไป Microsoft (เสียงของ Windows ไม่ส่งออกไปไหน)With online voices, text to be read is sent to Microsoft. Windows voices send nothing anywhere.
การเชื่อมแพลตฟอร์มPlatform connectionsแอพอ่านแชทสาธารณะของช่องที่คุณใส่ ไม่ได้ขอรหัสผ่านหรือ API key ใดๆThe app reads the public chat of the channels you enter; it never asks for passwords or API keys.
คู่มือนี้This manualโหลดเฉพาะฟอนต์จาก Google Fonts ถ้าไม่มีเน็ตจะใช้ฟอนต์ในเครื่องแทน ไม่มีตัวติดตามหรือคุกกี้Only fonts load from Google Fonts (local fonts are used offline). No trackers, no cookies.
04

เช็กลิสต์ทดสอบกับ OBS จริงก่อนไลฟ์ครั้งแรกOBS checklist before your first stream

  • ☐ เพิ่มวิดเจ็ตครบตามที่ใช้ ใส่ Width/Height ตรงกับในแอพ
  • ☐ กดทดสอบทุกวิดเจ็ต เห็นใน OBS และมีป้าย TEST
  • ☐ แจ้งเตือนที่มีเสียง: ติ๊ก Control audio via OBS และเห็นแถบเสียงขยับใน Audio Mixer
  • ☐ แก้ข้อความแจ้งเตือนแล้วกดเผยแพร่ OBS เปลี่ยนตามโดยไม่ต้องรีเฟรช
  • ☐ ปิดแล้วเปิดแอพใหม่ การตั้งค่ายังอยู่ และ OBS กลับมาแสดงเอง
  • ☐ Every widget you use is added, with Width/Height matching the app
  • ☐ Each widget’s test shows in OBS with the TEST label
  • ☐ Alerts with sound: Control audio via OBS is ticked and the Audio Mixer meter moves
  • ☐ Edit an alert’s text and publish: OBS updates without a refresh
  • ☐ Close and reopen the app: settings are kept and OBS comes back by itself
