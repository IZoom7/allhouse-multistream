06 · HELP

แก้ปัญหาและข้อมูล

อาการที่เจอบ่อยและวิธีแก้ การสำรองข้อมูล และข้อมูลของคุณไปที่ไหนบ้าง

01

อาการที่เจอบ่อย

OBS ไม่เห็นอะไรเช็กว่าแอพเปิดอยู่ ลิงก์ถูกวาง และกด “เผยแพร่ทุกวิดเจ็ต” แล้ว ลองกดปุ่มทดสอบของวิดเจ็ตนั้น
ทดสอบแล้วไม่ขึ้นดูข้อความแจ้งในแอพ: วิดเจ็ตอาจปิดอยู่ คิวพักอยู่ หรือยังไม่มีหน้าวิดเจ็ตเปิดใน OBS
เสียงแจ้งเตือนไม่ออกในไลฟ์ติ๊ก “Control audio via OBS” ใน Browser Source แล้วดูแถบเสียงใน OBS Audio Mixer
ไม่มีเสียงไทยเพิ่มเสียงไทยใน Windows (Settings → Time & language → Speech) หรือใช้เสียงออนไลน์ในหน้าบอทอ่านแชท
YouTube “กำลังลองใหม่”ช่องยังไม่ได้ไลฟ์ แอพจะต่อให้เองเมื่อเริ่มไลฟ์
TikTok “TikFinity is not running”เปิด TikFinity Desktop และล็อกอิน TikTok ไว้ก่อน แล้วกดเชื่อมต่อใหม่
เปิดแอพไม่ขึ้น: Port 19324มี Allhouse อีกตัวเปิดอยู่ ปิดตัวนั้นก่อนแล้วเปิดใหม่
แชทจริงไม่ถูกอ่านเช็กว่าบอทเปิดอยู่ แพลตฟอร์มนั้นไม่ได้ปิดเสียง และชื่อไม่ได้อยู่ในรายชื่อที่ไม่อ่าน
02

สำรองและนำเข้า

  • ส่งออกไฟล์สำรอง: เก็บการตั้งค่า วิดเจ็ต รูป และเสียงไว้ในไฟล์เดียว ไม่รวมประวัติแชทและลิงก์ OBS ส่วนตัว
  • นำเข้า: ข้อมูลจากไฟล์จะเข้ามาเป็น ฉบับร่าง OBS ยังแสดงแบบเดิมจนกว่าจะกดเผยแพร่ บอทอ่านแชทจะถูกปิดไว้ก่อนเพื่อความปลอดภัย
  • ล้างประวัติ: ลบแชทและกิจกรรมที่เก็บไว้ (เก็บล่าสุดสูงสุด 200 รายการ) และล้างคิวการแจ้งเตือน
03

ข้อมูลของคุณไปที่ไหน

ในเครื่องการตั้งค่า ประวัติ รูป เสียง และลิงก์ OBS เก็บในเครื่องนี้เท่านั้น
เสียงออนไลน์ถ้าเลือกเสียงออนไลน์ ข้อความที่จะอ่านจะถูกส่งไป Microsoft (เสียงของ Windows ไม่ส่งออกไปไหน)
การเชื่อมแพลตฟอร์มแอพอ่านแชทสาธารณะของช่องที่คุณใส่ ไม่ได้ขอรหัสผ่านหรือ API key ใดๆ
คู่มือนี้เป็นไฟล์ในเครื่อง โหลดเฉพาะฟอนต์จาก Google Fonts ถ้าไม่มีเน็ตจะใช้ฟอนต์ในเครื่องแทน
04

เช็กลิสต์ทดสอบกับ OBS จริงก่อนไลฟ์ครั้งแรก

  • ☐ เพิ่มวิดเจ็ตครบตามที่ใช้ ใส่ Width/Height ตรงกับในแอพ
  • ☐ กดทดสอบทุกวิดเจ็ต เห็นใน OBS และมีป้าย TEST
  • ☐ แจ้งเตือนที่มีเสียง: ติ๊ก Control audio via OBS และเห็นแถบเสียงขยับใน Audio Mixer
  • ☐ แก้ข้อความแจ้งเตือนแล้วกดเผยแพร่ OBS เปลี่ยนตามโดยไม่ต้องรีเฟรช
  • ☐ ปิดแล้วเปิดแอพใหม่ การตั้งค่ายังอยู่ และ OBS กลับมาแสดงเอง
