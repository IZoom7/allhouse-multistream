คู่มือ Allhouse

Allhouse รวมแชทและการแจ้งเตือนจาก Twitch, YouTube, Kick และ TikTok ไว้ที่เดียว แล้วส่งขึ้น OBS เป็นวิดเจ็ตที่แต่งได้เอง พร้อมบอทอ่านแชทภาษาไทยและอังกฤษ ทุกอย่างทำงานในเครื่องของคุณ

อยากทำอะไร เลือกหัวข้อได้เลย

เริ่มต้นใช้งานเปิดแอพ รู้จักหน้าจอ บันทึกอัตโนมัติ ข้อมูลทดสอบกับของจริง เชื่อมต่อแพลตฟอร์มTwitch, YouTube, Kick และ TikTok ผ่าน TikFinity วิดเจ็ต OBSเพิ่มแชท แจ้งเตือน ของขวัญ แบนเนอร์ เข้า OBS และตั้งค่าแต่ละตัว แชทและบอทอ่านแชทห้องแชท หน้าต่างแชทแยก เสียงไทย เลือกแพลตฟอร์มที่จะอ่าน CSS กำหนดเองแต่งวิดเจ็ตเอง: สี ขอบ ไล่สี เงา แอนิเมชัน + สนามทดลอง แก้ปัญหาและข้อมูลOBS ไม่ขึ้น เสียงไม่ออก สำรองข้อมูล ความเป็นส่วนตัว
01

เริ่มไลฟ์ได้ใน 5 ขั้น

  1. เปิดแอพดับเบิลคลิก Start Allhouse.cmd ในโฟลเดอร์โปรแกรม
  2. เชื่อมช่องของคุณหน้า “เชื่อมต่อแพลตฟอร์ม” ใส่ชื่อช่องแล้วกดเชื่อมต่อ
  3. เพิ่มวิดเจ็ตเข้า OBSหน้า “วิดเจ็ต OBS” คัดลอกลิงก์ไปเป็น Browser Source
  4. ส่งทดสอบกดปุ่มทดสอบของแต่ละวิดเจ็ต ต้องเห็นใน OBS ทันที
  5. เปิดบอทอ่านแชทหน้า “บอทอ่านแชท” เลือกเสียงและแพลตฟอร์มที่จะอ่าน

ในแอพ กดปุ่ม คู่มือ ที่แถบด้านบนได้ทุกเมื่อ แอพจะเปิดหน้าคู่มือที่ตรงกับหน้าที่คุณดูอยู่
