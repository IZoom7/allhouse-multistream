05 · CUSTOM CSS

แต่งวิดเจ็ต OBS ด้วย CSS ของคุณเองStyle your OBS widgets with your own CSS

คู่มือนี้สอนตั้งแต่ “ตรงไหนเรียกว่าอะไร” ไปจนถึงสีพื้นหลัง ขอบ ไล่สี (gradient) และแอนิเมชัน ทุกภาพในหน้านี้วาดด้วย CSS จริง ก๊อปโค้ดไปวางในช่อง CSS กำหนดเอง ของวิดเจ็ตได้เลย

From “what is each part called” to backgrounds, borders, gradients and animation. Every picture on this page is real CSS, so you can copy the code straight into a widget’s custom CSS box.

เริ่มต้นใช้ CSS กำหนดเองGetting started with custom CSS

  1. เลือกวิดเจ็ตPick a widgetไปที่ วิดเจ็ต OBS แล้วกดแท็บที่จะแต่ง เช่น แจ้งเตือนผู้ติดตามGo to OBS widgets and open the tab to style, e.g. the follow alert
  2. เปิดสวิตช์Turn it onใต้พรีวิว กด “ใช้ CSS กำหนดเอง (ขั้นสูง)” ช่องเขียนโค้ดจะโผล่ขึ้นมาUnder the preview, switch on “Use custom CSS (advanced)” and the code box appears
  3. เขียนหรือวางโค้ดWrite or paste codeพรีวิวเปลี่ยนทันที กด “ใส่โค้ดตัวอย่าง” ถ้ายังไม่รู้จะเริ่มตรงไหนThe preview updates instantly. Press “Insert example” if you’re not sure where to start
  4. กดเผยแพร่PublishOBS เปลี่ยนตามเมื่อกด “เผยแพร่ทุกวิดเจ็ต” ไม่ต้องรีเฟรช Browser SourceOBS updates when you press “Publish all widgets”; no Browser Source refresh needed
CSS คืออะไร: คือคำสั่งบอกหน้าตา เขียนเป็น “ชื่อชิ้นส่วน { คุณสมบัติ: ค่า; }” เช่น #card { border-radius: 0; } แปลว่า “กล่องการ์ด ให้มุมเหลี่ยม” ทุกบรรทัดในวงเล็บปีกกาต้องจบด้วย ;What is CSS? Rules that describe how things look, written as “part { property: value; }”. For example #card { border-radius: 0; } means “give the card square corners”. Every line inside the braces ends with ;

สีและพื้นหลังColours and backgrounds

ใช้ background เปลี่ยนพื้น color เปลี่ยนสีตัวอักษร สีเขียนได้หลายแบบ: #ff6b6b, rgb(255 107 107) หรือมีความโปร่งใส rgba(0,0,0,.5) (ตัวท้าย 0 = ใส, 1 = ทึบ)

background changes the fill, color changes the text. Colours can be #ff6b6b, rgb(255 107 107), or see-through with rgba(0,0,0,.5) (last number: 0 = clear, 1 = solid).

  background: #3a1d6e;
}
mintmint followed!
โปร่งใสครึ่งๆHalf see-through
#card {
  background: rgba(16,20,20,.35);
}
mintmint followed!
ไม่มีพื้นเลยNo background
#card {
  background: transparent;
  border-color: transparent;
}
ตัวแปรสีจากหน้าตั้งค่า: var(--accent) = สีหลัก, var(--text) = สีข้อความ, var(--bg) = สีพื้นตามความทึบที่ตั้งไว้ ใช้ตัวแปรแทนรหัสสีแล้ว ถ้าไปเปลี่ยนสีในหน้าตั้งค่า โค้ดของคุณจะเปลี่ยนตามเอง เช่น .chat b { color: var(--accent); }Colour variables from the settings: var(--accent) = accent, var(--text) = text colour, var(--bg) = background at your chosen opacity. Use them instead of fixed colours and your CSS follows whatever you pick in the settings, e.g. .chat b { color: var(--accent); }

ขอบ: ความหนา รูปแบบ สี และมุมBorders: width, style, colour and corners

เขียนรวดเดียวได้ว่า border: ความหนา รูปแบบ สี; เช่น border: 4px dashed #ffd84a; ส่วนมุมโค้งใช้ border-radius

ไล่สี (gradient)Gradients

gradient ใช้แทนสีพื้นได้เลย linear-gradient(ทิศทาง, สี1, สี2, …) ไล่เป็นเส้นตรง, radial-gradient ไล่เป็นวงกลม, conic-gradient หมุนรอบจุด

A gradient works anywhere a background colour does: linear-gradient(direction, colour1, colour2, …) runs in a line, radial-gradient in a circle, conic-gradient around a point.

แอนิเมชันพื้นฐานAnimation basics

แอนิเมชันมี 2 ส่วน: @keyframes บอกว่า “ขยับยังไง” (จุดเริ่ม 0% → จุดจบ 100%) และ animation บอกว่า “ใช้กับชิ้นไหน นานเท่าไร กี่รอบ”

Animation has two parts: @keyframes says how things move (start 0% → end 100%), and animation says which part moves, for how long, and how many times.

pulseชื่อ keyframeskeyframes name 1.2sนานต่อรอบlength per run ease-in-outจังหวะเร่ง/ผ่อนeasing infiniteวนตลอด (หรือใส่ 1, 3)forever (or 1, 3)
mintmint followed!
pulse เต้นตุบๆheartbeat
@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.06); }
}
#card {
  animation: pulse 1.2s ease-in-out infinite;
}
mintmint followed!
glow เรืองแสงเป็นจังหวะpulsing glow
@keyframes glow {
  0%, 100% { box-shadow: 0 0 6px var(--accent); }
  50% { box-shadow: 0 0 28px 6px var(--accent); }
}
#card {
  animation: glow 1.6s ease-in-out infinite;
}
mintmint followed!
shake สั่นตอนขึ้นshake on arrival
@keyframes shake {
  0%, 100% { transform: translateX(0); }
  20%, 60% { transform: translateX(-8px); }
  40%, 80% { transform: translateX(8px); }
}
#card {
  animation: shake .6s 3;  /* สั่น 3 รอบ *//* shake 3 times */
}
mintmint followed!
bounce-in หล่นลงมาเด้งdrop and bounce

  60%  { transform: translateY(8px); opacity: 1; }
  100% { transform: translateY(0); }

#card {
  animation: bounce-in .8s ease-out;
}

  to { filter: hue-rotate(360deg); }

  animation: hue 3s linear infinite;

แอนิเมชันเดิมของวิดเจ็ต (เด้งขึ้น / ค่อยๆ ปรากฏ / เลื่อนเข้า) ตั้งในหน้าตั้งค่า ถ้าจะใช้แอนิเมชันของคุณเองล้วนๆ ให้เลือก “ไม่มี” ในช่องแอนิเมชันก่อน จะได้ไม่ซ้อนกัน การ์ดแจ้งเตือนถูกสร้างใหม่ทุกครั้งที่มีคนติดตาม แอนิเมชันที่ไม่วนซ้ำ (เช่น bounce-in, shake 3) จะเล่นใหม่ทุกครั้งที่มีแจ้งเตือนThe widget’s built-in animation (pop / fade / slide) is set in the settings. To use only your own, choose “none” there first so they don’t stack. The alert card is rebuilt for every alert, so one-shot animations (bounce-in, shake 3) replay each time.

ข้อควรรู้และแก้ปัญหาGood to know and troubleshooting

ไม่เปลี่ยนใน OBSNo change in OBSลืมกด “เผยแพร่ทุกวิดเจ็ต” พรีวิวเปลี่ยนทันที แต่ OBS ใช้ฉบับที่เผยแพร่แล้วเท่านั้นYou forgot “Publish all widgets”. The preview updates at once; OBS only uses the published version.
ไม่เปลี่ยนเลยNo change at allเช็กว่าเปิดสวิตช์ “ใช้ CSS กำหนดเอง” แล้ว และทุกบรรทัดจบด้วย ; ส่วน { } ต้องเปิดปิดครบคู่Check “Use custom CSS” is on, every line ends with ; and every { has its }.
รูปไม่ขึ้นImage won’t loadวิดเจ็ตโหลดไฟล์จากเน็ตไม่ได้ (เพื่อความปลอดภัย) ใช้ปุ่ม “เพิ่มรูป / GIF” ในหน้าตั้งค่าแทน หรือใช้รูปแบบ data: URLWidgets can’t load files from the internet (for safety). Use “Add image / GIF” in the settings, or a data: URL.
ฟอนต์ไม่เปลี่ยนFont won’t changeฟอนต์จากเว็บ (Google Fonts) โหลดไม่ได้ ใช้ฟอนต์ที่มีในเครื่องได้ เช่น font-family: Tahoma;Web fonts (Google Fonts) can’t load. Use fonts installed on your PC, e.g. font-family: Tahoma;
ยาวสุดMaximum length20,000 ตัวอักษรต่อวิดเจ็ต20,000 characters per widget
ทำพัง?Broke it?ปิดสวิตช์ CSS กำหนดเอง วิดเจ็ตกลับเป็นหน้าตาเดิมทันที โค้ดยังเก็บไว้ให้Turn custom CSS off and the widget looks normal again instantly. Your code is kept.
