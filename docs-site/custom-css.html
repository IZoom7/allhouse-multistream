05 · CUSTOM CSS

แต่งวิดเจ็ต OBS ด้วย CSS ของคุณเอง

คู่มือนี้สอนตั้งแต่ “ตรงไหนเรียกว่าอะไร” ไปจนถึงสีพื้นหลัง ขอบ ไล่สี (gradient) และแอนิเมชัน ทุกภาพในหน้านี้วาดด้วย CSS จริง ก๊อปโค้ดไปวางในช่อง CSS กำหนดเอง ของวิดเจ็ตได้เลย

เริ่มต้นตรงไหนเป็นตรงไหนสีและพื้นหลังขอบไล่สีเงาแอนิเมชันสนามทดลองข้อควรรู้

01

เริ่มต้นใช้ CSS กำหนดเอง

  1. เลือกวิดเจ็ตไปที่ วิดเจ็ต OBS แล้วกดแท็บที่จะแต่ง เช่น แจ้งเตือนผู้ติดตาม
  2. เปิดสวิตช์ใต้พรีวิว กด “ใช้ CSS กำหนดเอง (ขั้นสูง)” ช่องเขียนโค้ดจะโผล่ขึ้นมา
  3. เขียนหรือวางโค้ดพรีวิวเปลี่ยนทันที กด “ใส่โค้ดตัวอย่าง” ถ้ายังไม่รู้จะเริ่มตรงไหน
  4. กดเผยแพร่OBS เปลี่ยนตามเมื่อกด “เผยแพร่ทุกวิดเจ็ต” ไม่ต้องรีเฟรช Browser Source
CSS คืออะไร: คือคำสั่งบอกหน้าตา เขียนเป็น “ชื่อชิ้นส่วน { คุณสมบัติ: ค่า; }” เช่น #card { border-radius: 0; } แปลว่า “กล่องการ์ด ให้มุมเหลี่ยม” ทุกบรรทัดในวงเล็บปีกกาต้องจบด้วย ;

03

สีและพื้นหลัง

ใช้ background เปลี่ยนพื้น color เปลี่ยนสีตัวอักษร สีเขียนได้หลายแบบ: #ff6b6b, rgb(255 107 107) หรือมีความโปร่งใส rgba(0,0,0,.5) (ตัวท้าย 0 = ใส, 1 = ทึบ)

mintmint followed!
พื้นสีทึบ
#card {
  background: #3a1d6e;
}
mintmint followed!
โปร่งใสครึ่งๆ
#card {
  background: rgba(16,20,20,.35);
}
mintmint followed!
ไม่มีพื้นเลย
#card {
  background: transparent;
  border-color: transparent;
}
ตัวแปรสีจากหน้าตั้งค่า: var(--accent) = สีหลัก, var(--text) = สีข้อความ, var(--bg) = สีพื้นตามความทึบที่ตั้งไว้ ใช้ตัวแปรแทนรหัสสีแล้ว ถ้าไปเปลี่ยนสีในหน้าตั้งค่า โค้ดของคุณจะเปลี่ยนตามเอง เช่น .chat b { color: var(--accent); }

05

ไล่สี (gradient)

gradient ใช้แทนสีพื้นได้เลย linear-gradient(ทิศทาง, สี1, สี2, …) ไล่เป็นเส้นตรง, radial-gradient ไล่เป็นวงกลม, conic-gradient หมุนรอบจุด

mintmint followed!
linear เส้นตรง เฉียง 135°
#card {
  background: linear-gradient(
    135deg, #ff5f6d, #ffc371);
}
mintmint followed!
radial วงกลมจากมุม
#card {
  background: radial-gradient(
    circle at 30% 20%,
    #6a5cff, #12121c 70%);
}
mintmint followed!
conic สีจอยสี่สี
#card {
  background: conic-gradient(
    #285bb5, #bd3933,
    #f0cb45, #287b49, #285bb5);
}
mintmint followed!
ขอบไล่สี พื้นทึบ + ขอบรุ้ง
#card {
  border: 4px solid transparent;
  background:
    linear-gradient(#141818, #141818) padding-box,
    linear-gradient(90deg, #ff5f6d, #ffc371, #2ec4b6) border-box;
}
mintmint followed!

07

แอนิเมชันพื้นฐาน

แอนิเมชันมี 2 ส่วน: @keyframes บอกว่า “ขยับยังไง” (จุดเริ่ม 0% → จุดจบ 100%) และ animation บอกว่า “ใช้กับชิ้นไหน นานเท่าไร กี่รอบ”

pulseชื่อ keyframes 1.2sนานต่อรอบ ease-in-outจังหวะเร่ง/ผ่อน infiniteวนตลอด (หรือใส่ 1, 3)
mintmint followed!
pulse เต้นตุบๆ
@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.06); }
}
#card {
  animation: pulse 1.2s ease-in-out infinite;
}
mintmint followed!
glow เรืองแสงเป็นจังหวะ
@keyframes glow {
  0%, 100% { box-shadow: 0 0 6px var(--accent); }
  50% { box-shadow: 0 0 28px 6px var(--accent); }
}
#card {
  animation: glow 1.6s ease-in-out infinite;
}
mintmint followed!
shake สั่นตอนขึ้น
@keyframes shake {
  0%, 100% { transform: translateX(0); }
  20%, 60% { transform: translateX(-8px); }
  40%, 80% { transform: translateX(8px); }
}
#card {
  animation: shake .6s 3;  /* สั่น 3 รอบ */
}
mintmint followed!
bounce-in หล่นลงมาเด้ง
@keyframes bounce-in {
  0%   { transform: translateY(-60px); opacity: 0; }
  60%  { transform: translateY(8px); opacity: 1; }
  100% { transform: translateY(0); }
}
#card {
  animation: bounce-in .8s ease-out;
}
mintmint followed!
rainbow สีวนไปเรื่อยๆ
@keyframes hue {
  to { filter: hue-rotate(360deg); }
}
#card {
  animation: hue 3s linear infinite;
}
บ้านข้างๆ · YouTubeไลฟ์วันนี้สนุกมาก!
float ลอยขึ้นลง (แชท)
@keyframes float {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-8px); }
}
.chat {
  animation: float 2.4s ease-in-out infinite;
}
แอนิเมชันเดิมของวิดเจ็ต (เด้งขึ้น / ค่อยๆ ปรากฏ / เลื่อนเข้า) ตั้งในหน้าตั้งค่า ถ้าจะใช้แอนิเมชันของคุณเองล้วนๆ ให้เลือก “ไม่มี” ในช่องแอนิเมชันก่อน จะได้ไม่ซ้อนกัน การ์ดแจ้งเตือนถูกสร้างใหม่ทุกครั้งที่มีคนติดตาม แอนิเมชันที่ไม่วนซ้ำ (เช่น bounce-in, shake 3) จะเล่นใหม่ทุกครั้งที่มีแจ้งเตือน

09

ข้อควรรู้และแก้ปัญหา

ไม่เปลี่ยนใน OBSลืมกด “เผยแพร่ทุกวิดเจ็ต” พรีวิวเปลี่ยนทันที แต่ OBS ใช้ฉบับที่เผยแพร่แล้วเท่านั้น
ไม่เปลี่ยนเลยเช็กว่าเปิดสวิตช์ “ใช้ CSS กำหนดเอง” แล้ว และทุกบรรทัดจบด้วย ; ส่วน { } ต้องเปิดปิดครบคู่
รูปไม่ขึ้นวิดเจ็ตโหลดไฟล์จากเน็ตไม่ได้ (เพื่อความปลอดภัย) ใช้ปุ่ม “เพิ่มรูป / GIF” ในหน้าตั้งค่าแทน หรือใช้รูปแบบ data: URL
ฟอนต์ไม่เปลี่ยนฟอนต์จากเว็บ (Google Fonts) โหลดไม่ได้ ใช้ฟอนต์ที่มีในเครื่องได้ เช่น font-family: Tahoma;
ยาวสุด20,000 ตัวอักษรต่อวิดเจ็ต
ทำพัง?ปิดสวิตช์ CSS กำหนดเอง วิดเจ็ตกลับเป็นหน้าตาเดิมทันที โค้ดยังเก็บไว้ให้
